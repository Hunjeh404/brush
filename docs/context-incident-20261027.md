1. 최신 저장소를 `/workspace/projects/brush`로 정리하고 기존 경로를 연결했다. 다른 이전 복제본은 삭제하지 않았다.
2. 시작 시 `node scripts/work-status.mjs`로 짧은 현황만 읽고 `WORK_STATE.md`에서 재개한다.
3. `AGENTS.md`에 도구 검색 범위, 텍스트 출력 상한, 큰 로그 파일 저장, 원본 응답 중복 출력 금지, 이미지 재사용, SHA별 검증 기록 규칙을 남겼다.
4. 기능의 로컬 완료와 원격/배포 완료를 분리해서 기록한다. 이전 대화가 없더라도 마지막 작업을 다시 생성하지 않고 다음 단계로 간다.

플랫폼의 대화 상한이나 오류를 여기서 수정할 수는 없다. 이번 조치는 확인한 불필요한 출력과 재개 비용을 줄인다. 이전 경고의 직접 원인까지 밝혀냈거나 한도 재발을 완전히 차단했다고 주장하지 않는다.
